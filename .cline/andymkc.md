# General Environment & Response Guidelines

- **Environment:** Windows running a Bash shell (e.g., Git Bash / WSL style). Use Bash-compatible commands (e.g., `ls`, `grep`, `pwd`) rather than Windows PowerShell or CMD commands.
- **Tone & Length:** Be extremely brief. Omit filler words, pleasantries, and unnecessary preamble. Use just enough words to get the point across.
- **Git Restrictions:** Never execute any git commands unless explicitly directed to.
- **Formatting:** When presenting structured information, comparisons, or multi-item data, always prefer using a Markdown table format.
